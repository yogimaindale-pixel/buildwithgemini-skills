# Vertex AI RAG Engine Agent

An ADK agent grounded on enterprise documents via Vertex AI RAG Engine with A2UI compatibility.

## Contents
- `rag_agent.py`: ADK Agent with integrated `search_documents` function tool.
- `test_rag_a2ui_compat.py`: Test suite verifying RAG retrieval and A2UI formatting compatibility.

## Usage

Run the agent:

```bash
python3 rag_agent.py
```

Run RAG and A2UI compatibility verification test:

```bash
python3 test_rag_a2ui_compat.py
```
