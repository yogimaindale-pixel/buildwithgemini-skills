# Project Brief: Persistent Memory Bank Agent

## Overview
This project demonstrates adding cross-session long-term memory to an ADK agent using Agent Platform's **Vertex AI Memory Bank**.

## Key Concepts
- **Cross-Session Persistence**: Retains user preferences and key facts across separate chat conversations.
- **PreloadMemoryTool**: Preloads user-specific facts at the beginning of each session.
- **Memory-Generation Callbacks**: Automatically extracts and persists relevant facts from user messages during conversation flow.
