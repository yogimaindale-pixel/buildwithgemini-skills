# Build with Gemini: Skills & Projects Repository

Welcome to the **Build with Gemini** repository! This repository contains skills, rules, agent templates, and standalone runnable project implementations for Google Agent Development Kit (ADK), Vertex AI Agent Engine, and AI Governance.

---

## 📁 Projects & Runnable Code (`projects/`)

Each project below is a complete, standalone implementation based on the skills in this repository:

1. **[NovaSmart AI Governance Lab](projects/novasmart-ai-governance-lab/)**
   - **Brief**: [project_brief.md](projects/novasmart-ai-governance-lab/project_brief.md) | **Guide**: [README.md](projects/novasmart-ai-governance-lab/README.md)
   - Enterprise security engine for shadow agent discovery, identity privilege auditing, and content safety screening.

2. **[Agent Frontend Chat UI](projects/agent-frontend-chat-ui/)**
   - **Brief**: [project_brief.md](projects/agent-frontend-chat-ui/project_brief.md) | **Guide**: [README.md](projects/agent-frontend-chat-ui/README.md)

3. **[Vertex AI RAG Engine Agent](projects/vertex-rag-engine-agent/)**
   - **Brief**: [project_brief.md](projects/vertex-rag-engine-agent/project_brief.md) | **Guide**: [README.md](projects/vertex-rag-engine-agent/README.md)

4. **[Persistent Memory Bank Agent](projects/memory-bank-agent/)**
   - **Brief**: [project_brief.md](projects/memory-bank-agent/project_brief.md) | **Guide**: [README.md](projects/memory-bank-agent/README.md)

## 🛠️ Skills & Customizations (`.agents/skills/`)

- `novasmart-governance-lab`: Security steering skill for the Head of AI Platform & Security.
- `publish-to-github`: Device-flow GitHub publishing tool for participant projects.
- `build-agent-frontend`: Custom frontend proxy and UI setup for ADK / Agent Engine deployments.
- `enable-a2ui`: A2UI display card formatter for ADK agents.
- `build-rag`: Vertex AI RAG Engine corpus configuration and retrieval function tools.
- `setup-memory-bank`: Vertex AI Memory Bank integration for cross-session long-term memory.
- `record-demo`: Web-based demo recording tools.
- `troubleshoot-lab-setup`: Automated lab environment verification.
- `pick-your-agent-project`: Design and planning assistant for workshop agent projects.
